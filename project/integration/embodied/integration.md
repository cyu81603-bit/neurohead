# 全链路整合 v6.3（2026-10-30）

正式工程说明位于项目根目录`FINAL_PROJECT_V6_3.md`。启动入口保持`F:\NeuroHead\启动全链路对话.cmd`，板卡断电后使用`F:\NeuroHead\启动机器人.cmd`恢复。

## 当前行为

- 唯一硬件发送者为原`LifelikeSession`。本目录LLM/TTS只通过`IntentLink`传递表情和语音能量；不并行运行另一套UDP调度器，不提供原始PWM或启动控制权限。
- 下颚MG995：CH21／Pin24，闭嘴1300μs、张嘴1200μs。实际两点直接切换已验证；普通平滑插值不用于该通道。
- 语音结束、静音和过期能量回闭嘴，持续有声也有开合间隔。与眉、唇、颊共用语音事件；眼颈追踪继续独立计算。
- 自动眨眼继续关闭。仅使用外接USB Cam，不回退内置相机。
- Ollama、ASR和SAPI/TTS继续复用现有F盘环境。程序启动为空闲，不自动输出PWM、打开相机或监听麦克风。

## 使用

恢复22路接线后，在v6.3主控确认接线并开始会话、打开USB Cam、启用眼颈接力及表情。在对话窗口连接表情联动后进行文字／语音对话；语音文件使用表情窗口的播放入口。

现场最近只确认了下颚Pin24，其他PWM曾全部拔开。整机启用前应在舵机断电时恢复接线并托稳头部。旧v6.2窗口保留时不得开始控制或保存旧配置。

## 验证边界

实物：下颚1300→1200→1300每点3秒，操作者确认舵臂和嘴巴明显动作、最后自然闭合。供电表观察最低5.16V、停稳5.24V；万用表无法据此排除极短瞬变。

软件：固定端点、音量滞回、语音结束闭嘴、重复开合、停表情闭嘴保持、紧急停输出、眼颈通道保持、启动空闲和原对话功能通过回归。

连续语音节奏及所有22路同时运行仍需实物联合验收，不将软件通过冒充现场验收。原交接包和整合前备份均保留。
