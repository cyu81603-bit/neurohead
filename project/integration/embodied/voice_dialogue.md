# 语音对话 v3

双击 `F:\NeuroHead\启动语音对话.cmd`。使用 F 盘现有 Ollama 和 Qwen3.5:4b，缺少本地服务时会后台启动已有安装，不下载模型。

1. 等待中文就绪提示后，直接对麦克风说一句话，停顿约0.7秒后识别并回答。
2. 环境声较大或不容易断句时：点“开始说话”，讲完点“结束发送”。每轮最长15秒。
3. 也可以在输入框打字、回车发送；回答会显示文字并播放语音。
4. 点“停止说话”停止当前播报。点“语音监听 开／关”暂停或恢复麦克风。
5. “测试语音播放”可以检查扬声器。关闭按钮暂停对话并保留操作窗口。

当前使用系统默认 Realtek 麦克风阵列和扬声器。相机仅复用已有 USB Cam 共享画面，不打开内置摄像头。

该入口为纯语音/文字对话，没有表情联动按钮和板卡连接能力；正在运行的眼颈追踪保留在原主控。带表情的整合入口仍为 `启动全链路对话.cmd`，需按现场状态接管与确认。

2026-10-29：修复背景声导致一直录音不发送的问题，加入背景音适应、停顿断句和无静音时也生效的15秒硬上限；加入手动录音发送。现场操作者已确认“能听到，已能对话”。
