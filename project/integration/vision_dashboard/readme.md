# 实时视觉处理流程页
入口：项目根目录“启动视觉流程展示.cmd”；本地地址 http://127.0.0.1:8766 。新打开的同学三栏界面增加“视觉处理流程”按钮；当前已运行窗口无需重启即可独立打开本页。

只使用Python标准库提供回环地址上的只读GET接口，读取现有build/usb_cam_shared.json和新鲜head_runtime_*.json。不导入任何舵机控制/相机模块，不创建UDP客户端，不改变运行状态。原USB Cam预览是唯一采集者；本页刷新5Hz，源程序按原节奏运行。

显示采集/预处理/检测选择/误差/协调五步，源帧率估计、原检测调用总耗时（含预处理）、帧龄、帧号、人脸框、归一化误差与五路主控记录。没有独立计时的阶段显示说明，不填假耗时。图像已被源程序标注，未声称有原始帧。预处理尺寸画面是从共享标注帧重建的示意，不是模型内部输入。YuNet实际为保持比例缩放至320方形画布、仅右侧/下侧填黑边；Haar分支另作说明。

人脸不存在时保留新鲜图像、清除目标；帧龄超过750ms或采集报错时清除图像和目标。主控状态超过3s不显示，主控活动掩码为0时PWM列为--，避免把空闲缓存当成正在输出。主控快照与图像没有硬件同步，不把两者误称同一帧闭环测量。页面暂停仅停止页面读取。

本页只显示实际共享的字段：原检测器没有输出置信度、关键点、每阶段耗时，不在本页捏造。未来如需这些真实中间结果，需要单独给视觉源增加埋点并安排预览进程切换，当前没有改动该源。

验证：test_dashboard.py包含新鲜/过期、无人脸、无效坐标、活动主控选择、HTTP只读和路由隔离等6项测试；原整合窗口空闲自检通过。当前已有相机源接入，本页已实际打开，未启动舵机。
