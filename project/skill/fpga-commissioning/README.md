# 执行机构与 AI 控制协作

适用：FPGA 控制的机器人、云台、电机/舵机及多来源动作控制；板卡和通道映射独立。
不是通用驱动或现场自动测试器，不替代机构/供电/失能设计。Python 3.9+、标准库。

```sh
python scripts/trial_evidence.py assets/digital-only.example.json --now 1005
```

示例为合成数据，输出数字证据满足、实物未验证，exit 0 表示“声明一致”，不表示
“机器人通过”。加入 physical_motion_verified 声明会失败；非模拟使用时不要传
`--now`，工具取当前时间以检查证据新鲜度。JSON 的 `mode=simulation` 永不支持实物
或波形声明。source 为记录路径/仪器原始记录，不是模型口头结论；脚本只审核结构
和声明，不验证记录真实性、文件内容或操作者身份。

来源与效果：早期 Pin3/Pin10 误配说明寄存器读数不能证明接线；R6.7 上下眼球数字
回读到位但舵盘不动，仍保留故障。CH6/7 相机遮挡要求过滤全部输出路径；并发聊天/
动作两路共享快照、取消代次的经验支持防迟到结果。原项目模型措辞仍存在失败，
不能声称所有语言正确。详见包根 SOURCES.md。

离线测试覆盖过期、build 改变、模拟证据冒充实物、缺实物观察和闭环实测；没有
发 UDP、改线、加载位流、启动主控或执行动作。案例的 1500μs 只代表当时电气参考，
不是所有舵机的机械中位，也不是本包通用安全范围。
