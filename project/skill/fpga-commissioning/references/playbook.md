# 证据驱动的排障与协作模板

|触发观察|下一步区分检查|失效条件与验收|
|---|---|---|
|命令 accepted 但完全不动|对应逻辑通道、顶层/XDC/接头针脚，接头处电压和波形，再已知正常器件对照|没有外部测量时不能排除信号；不直接判舵机坏|
|空载能动、接杆后卡住|断能后按机构规范检查干涉/预紧/自由度，再在已验证区间试验|电气中位≠机械中位；不按软件角度推实际角度|
|固定点摆动／嗡鸣|记录供电与负载，缩小原因范围，按具体型号换已知正常件|无位置反馈的软件补偿不能修复内部故障|
|启动表情便挡镜头|逐个检查 enable/neutral/return/watchdog 对禁用通道的输出，测试仲裁|只封动作入口仍可能遮挡；改变相机视野会改变跟踪闭环|
|脖子不动但眼球居中|人脸检测新鲜度、边界/限幅、眼颈所有权和相机安装关系|图像居中不证明头架正对，没有姿态反馈不报真实角度|
|取消后仍说话或动作|检查请求ID、取消代次、结果消费与记忆写回|HTTP 返回不代表仍获执行许可；放弃迟到结果|
|“再来一次”重放错动作|同次上下文快照、唯一指代、当前请求优先、白名单动作ID|引用/否定/普通问句不触发；语音措辞另验收|
|掉电后无响应|校验资产、启动链和只读 ID/通信，检查唯一控制者|恢复到待机≠允许动作；原接线/安装可能已变|

可复用提示词：

“目标行为：{目标}。当前已确认现场条件：{时间/接线/供电/安装}。冻结资产：{哈希}。
契约：{版本/字段/单位/通道owner/失能策略}。原始观察：{数字、测量、实物分列}。
未知：{列表}。提出能区分原因的最小检查，先离线验证；不把回读当物理量，不在证据
缺失时扩大范围。输出每项结论的证据和失效条件。”

软件验收用例模板：同一通道两 owner 竞争；禁止通道经过全部输出路径；过期目标；
取消后迟到；旧控制器重连；build/profile 改变；一条模型路线失败；重复/引用/否定请求。
这组模板来自项目经验，需对目标系统实现实际测试，不可将模板本身称作通过。
