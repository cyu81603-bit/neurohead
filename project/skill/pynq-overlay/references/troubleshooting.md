# 触发条件与定位

|观察|最小区分检查|停止/失效条件|
|---|---|---|
|没有 register_map|检查同名 HWH、HWH 寄存器段、实际 driver 类型|缺元数据时不猜 offset|
|找不到 IP|比较完整层级路径、VLNV、ip_dict 与该次 HWH|不要把旧实例名字写死|
|读总为 0/总线挂起|先核对 part、地址窗口、时钟和复位，再读已定义 ID|MMIO 总线阻塞不受普通 Python timeout 保证，须板级恢复|
|加载成功但外部无输出|沿逻辑通道→顶层端口→XDC→封装管脚→接头→负载验证|内部寄存器不证明输出引脚正确|
|换 overlay 后旧对象可访问|销毁旧引用并重新绑定，检查并发控制者|不在 DMA 活动时重新配置|
|版本不兼容|记录实际 PYNQ/镜像/Vivado，检查驱动支持版本|不默认 ignore_version=True|

来源不是硬件通用接线规范；NeuroHead 的 J10/Pin10/V15 仅是一次历史案例。
